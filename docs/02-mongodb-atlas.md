# 2. Create a free MongoDB Atlas database

MongoDB Atlas is MongoDB's hosted service. The free "M0" tier is enough for this project.

## Step 1 — Create an account

1. Go to <https://www.mongodb.com/cloud/atlas/register>.
2. Sign up and verify your email.

## Step 2 — Create a free cluster

1. Choose **Create** (or **Build a Database**).
2. Pick the **M0 Free** tier.
3. Choose any provider and the region closest to you.
4. Name the cluster (for example `Cluster0`) and click **Create Deployment**.

Creating the cluster takes 1–3 minutes.

## Step 3 — Create a database user

Atlas usually prompts for this right after creating the cluster. Otherwise go to
**Security → Database Access → Add New Database User**.

1. Authentication method: **Password**.
2. Username: for example `inkwell_app`.
3. Password: click **Autogenerate** and **copy it somewhere safe** — you cannot see it again.
4. Role: **Read and write to any database**.
5. Click **Add User**.

> If your password contains `@`, `:`, `/` or `#`, it must be percent-encoded in the
> connection string (`@` becomes `%40`). Using an autogenerated alphanumeric password avoids this.

## Step 4 — Allow network access

Go to **Security → Network Access → Add IP Address**.

- For local development: **Add Current IP Address**.
- For Vercel: Vercel's servers have changing IPs, so add `0.0.0.0/0` ("Allow access from
  anywhere"). Your database is still protected by the username and password.

Click **Confirm**.

## Step 5 — Copy the connection string

1. Go to **Database → Connect → Drivers**.
2. Driver: **Node.js**, latest version.
3. Copy the string. It looks like:

```text
mongodb+srv://inkwell_app:<password>@cluster0.abcde.mongodb.net/?retryWrites=true&w=majority
```

4. Replace `<password>` with the real password.
5. Add a database name right after `.net/` — this project uses `inkwell`:

```text
mongodb+srv://inkwell_app:SuperSecret123@cluster0.abcde.mongodb.net/inkwell?retryWrites=true&w=majority
```

That final string is your `MONGODB_URI`. Put it in `.env` (see the next guide).

## Step 6 — Check the connection

```bash
npm run dev
```

You should see `MongoDB connected: ...` in the terminal.

### Common errors

| Message                                     | Cause and fix                                                     |
| ------------------------------------------- | ----------------------------------------------------------------- |
| `MONGODB_URI is missing`                    | `.env` file missing or the variable is misspelled.                 |
| `bad auth : authentication failed`          | Wrong username/password, or `<password>` was never replaced.       |
| `Could not connect to any servers`          | Your IP is not in Network Access, or you are behind a strict VPN.  |
| `querySrv ENOTFOUND`                        | The cluster hostname was copied incorrectly.                       |

## How the app stores data

Two collections are created automatically the first time they are used:

- `users` — one document per account
- `posts` — one document per blog post
- `sessions` — login sessions (created by `connect-mongo`)
